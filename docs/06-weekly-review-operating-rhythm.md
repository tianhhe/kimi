# 周复盘运营节奏

更新日期：2026-07-02

## 1. 复盘目的

周复盘只回答 4 个问题：

1. 哪些人群和任务值得继续投？
2. 哪些内容结构值得复制？
3. 哪些达人值得复投？
4. 哪些产品承接或转化路径需要修？

## 2. 会议机制

| 项目 | 设置 |
|---|---|
| 时间 | 每周五 16:00-17:00 |
| 参会人 | 增长负责人、内容负责人、达人运营、数据、PMM |
| 输入材料 | 内容数据、达人数据、转化数据、竞品动态、用户评论 |
| 输出材料 | 下周内容排期、达人复投名单、实验清单、问题 owner |

## 3. 会议议程

| 时间 | 议程 | 产出 |
|---|---|---|
| 0-10 分钟 | 看北极星和主指标 | 本周是否达标 |
| 10-25 分钟 | 看内容 Top/Bottom | 可复制结构、失败原因 |
| 25-35 分钟 | 看达人表现 | 复投/停投名单 |
| 35-45 分钟 | 看转化漏斗 | 下周需要修的承接点 |
| 45-55 分钟 | 定下周实验 | 3-5 个实验 |
| 55-60 分钟 | 分配 owner | 行动清单 |

## 4. 内容复盘规则

每周把内容分成 4 类：

| 类型 | 判定 | 下周动作 |
|---|---|---|
| 爆发内容 | 曝光和转化都高 | 拆结构，复刻 3 条 |
| 潜力内容 | 曝光低但转化高 | 改标题封面，换渠道再发 |
| 声量内容 | 曝光高但转化低 | 保留话题，重做 CTA |
| 无效内容 | 曝光和转化都低 | 停止，记录原因 |

## 5. 达人复盘规则

| 数据表现 | 判断 | 动作 |
|---|---|---|
| 互动质量高，评论有具体任务 | 人群匹配 | 继续合作 |
| 播放高但评论泛 | 偏泛娱乐/泛工具 | 降低预算 |
| 收藏高但点击低 | CTA 不够清晰 | 重写置顶评论和落地页 |
| 点击高但任务完成低 | 承接问题 | 补教程和模板 |

## 6. 下周实验池

每周最多同时跑 5 个实验，避免团队失焦。

实验类型：

1. 人群实验：同一任务换人群表达。
2. 场景实验：同一人群换任务场景。
3. 标题实验：同一内容换标题和封面。
4. CTA 实验：模板领取、评论关键词、直接打开 Kimi。
5. 达人实验：同 brief 给不同类型达人。

## 7. 复盘文档写法

使用 `templates/weekly-review-template.md`。每次复盘必须写清楚：

1. 本周结论，不超过 5 条。
2. 本周最好内容和最差内容，各至少 3 条。
3. 本周达人复投/停投名单。
4. 本周竞品值得学习或防守的动作。
5. 下周只做哪些实验，谁负责，什么时候看结果。
