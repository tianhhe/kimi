# 内容栏目与选题体系

更新日期：2026-07-02

## 1. 内容总原则

Kimi 内容必须从用户任务出发，而不是从功能出发。每条内容至少满足 3 个条件：

1. 有明确人群：谁会需要。
2. 有明确任务：TA 要完成什么。
3. 有明确结果：用 Kimi 后能得到什么。

推荐内容结构：

痛点钩子 -> 输入材料 -> Kimi 操作过程 -> 结果展示 -> 可复制模板/口令 -> 评论互动。

## 2. 栏目矩阵

| 栏目 | 定位 | 适合渠道 | 频率 | 核心指标 |
|---|---|---|---|---|
| Kimi 完成一个真实任务 | 展示复杂任务交付能力 | 抖音、小红书、B 站 | 每周 3-5 条 | 完播、收藏、转化 |
| 某某行业怎么用 Kimi | 行业/岗位教育 | 小红书、知乎、B 站 | 每周 2-3 条 | 收藏、搜索、关注 |
| Kimi 模板库 | 低门槛促首用 | 小红书、微博、社群 | 每周 3 条 | 模板领取、复制 |
| Kimi 对比实验室 | 对竞品或旧方法做对比 | B 站、知乎、视频号 | 每周 1-2 条 | 评论、转发、停留 |
| 用户工作流改造 | UGC 和案例复盘 | 小红书、B 站 | 每周 1-2 条 | 投稿、私信、转化 |
| 发布节点速递 | 配合功能/活动 | 全渠道 | 按节点 | 点击、注册、任务完成 |

## 3. 场景选题池

### 3.1 学习与研究

| 选题 | 输入 | 输出 |
|---|---|---|
| 3 小时读完一篇英文论文 | PDF/链接 | 摘要、术语表、研究问题、答辩问题 |
| 期末复习资料太散怎么办 | 课件、笔记 | 7 天复习计划、重点题型 |
| 文献综述从 0 到 1 | 10 篇论文 | 主题聚类、观点对比、综述框架 |
| 论文答辩模拟 | 论文稿 | 评委问题、回答提纲 |

### 3.2 职场办公

| 选题 | 输入 | 输出 |
|---|---|---|
| 会议录音变成行动清单 | 录音转写/纪要 | 决策、待办、负责人、风险 |
| 老板要一份竞品分析 | 竞品链接/截图 | 对比表、机会点、汇报大纲 |
| 周报不再流水账 | 工作记录 | 成果、问题、下周计划 |
| 把一堆材料变成汇报 PPT 大纲 | 文档/网页 | 结构化汇报稿 |

### 3.3 内容创作

| 选题 | 输入 | 输出 |
|---|---|---|
| 一条爆款笔记怎么拆 | 爆款链接 | 标题结构、钩子、内容骨架 |
| 用 Kimi 做 30 天选题 | 账号定位 | 选题表、脚本角度、发布节奏 |
| 把长文变成短视频脚本 | 文章/报告 | 口播稿、分镜、标题 |

### 3.4 求职与个人发展

| 选题 | 输入 | 输出 |
|---|---|---|
| 简历按 JD 重写 | 简历 + JD | 匹配版简历、面试问题 |
| 面试前 30 分钟准备 | 岗位描述/公司资料 | 公司研究、岗位问题、回答提纲 |
| 实习经历不会写 | 项目描述 | STAR 版本、量化表达 |

### 3.5 产品/运营/市场

| 选题 | 输入 | 输出 |
|---|---|---|
| 一小时做活动复盘 | 活动数据 | 结论、问题、下次策略 |
| 快速搭建 GTM 计划 | 产品说明 | 目标人群、渠道、内容、指标 |
| 用户访谈怎么整理 | 访谈记录 | 需求聚类、用户画像、机会点 |

## 4. 单条内容生产标准

| 模块 | 标准 |
|---|---|
| 标题 | 包含人群/任务/结果，避免纯功能词 |
| 首屏 | 3 秒内出现痛点或结果截图 |
| 过程 | 至少展示 2 个关键操作步骤 |
| 结果 | 展示完整输出，不只展示一句回答 |
| CTA | 引导用户复制模板、评论领取、打开 Kimi 试做 |
| 复用 | 内容 brief 必须可沉淀到模板库 |

## 5. 标题公式

| 类型 | 公式 | 示例 |
|---|---|---|
| 任务结果型 | 我用 Kimi 把 X 变成 Y | 我用 Kimi 把 20 页资料变成 5 分钟汇报 |
| 人群痛点型 | X 人群最该收藏的 Kimi 工作流 | 研究生最该收藏的 Kimi 文献综述工作流 |
| 对比型 | 不用 Kimi vs 用 Kimi | 不用 Kimi 写周报 vs 用 Kimi 写周报 |
| 节点型 | X 前必须准备的 Kimi 模板 | 面试前必须准备的 3 个 Kimi 模板 |
| 挑战型 | 给 Kimi 一个 X，它能做出什么 | 给 Kimi 一个岗位 JD，它能做出什么 |

## 6. 发布节奏建议

| 星期 | 内容类型 |
|---|---|
| 周一 | 办公/学习高频任务，承接工作周开始 |
| 周二 | 行业/岗位教程 |
| 周三 | 模板库内容，促收藏和试用 |
| 周四 | 对比实验或深度案例 |
| 周五 | 周复盘、用户案例、轻量互动 |
| 周末 | 学习、求职、创作类长内容 |
