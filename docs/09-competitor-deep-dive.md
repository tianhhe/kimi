# 竞品深拆：功能、GTM、社媒表达

更新日期：2026-07-02

## 1. 竞品选择

本轮优先看 6 类对象：

| 对象 | 为什么看 |
|---|---|
| Claude / Claude Cowork | 用户教育、AI Fluency、工作协作心智最完整 |
| OpenAI Codex | 从开发者产品向非代码工作流扩展，是 Kimi Work 的重要参照 |
| Trae Work | 国内外都在讲 AI-native workspace，产品开发和工作模式表达相近 |
| Qoder Work | 明确把 agent 能力从代码扩展到工作交付 |
| WorkBuddy | 腾讯系全场景 AI 工作台，强职场/企业/IM 场景 |
| Kimi Work / Kimi Agent | 我们自己的差异化落点 |

## 2. 横向矩阵

| 产品 | 主打功能 | GTM 主叙事 | 社媒内容风格 | Kimi 应对 |
|---|---|---|---|---|
| Claude / Cowork | AI assistant、Projects、Artifacts、Skills、connectors、Cowork | 会用 AI 是一种工作能力，Claude 是可信协作者 | 学院化、职业化、行业化、案例化 | 学习教育体系，但用中文强场景表达 |
| Codex | 代码代理、任务执行、PR、调试，也延伸到报告、仪表盘、内容资产 | 把目标交给 Codex，产出可用成果 | 产品演示、客户案例、角色场景、工作流标题 | 把 Kimi Work 讲成非代码人群也能用的任务代理 |
| Trae Work | Work/Design/Code 多模式，AI-native workspace | Let TRAE work for you，产品开发链路一体化 | 开发者友好、产品构建、效率演示 | 避免只打开发场景，抢办公/研究/运营/创作 |
| Qoder Work | 桌面 agent、浏览器自动化、本地文件、Word/Excel/PPT/PDF、Skills/MCP、IM channels | Describe it. Automate it. Deliver it. | 前后耗时对比、case study、交付物展示 | 用“中文资料 + 多文件 + 多工具 + 最终交付物”反击 |
| WorkBuddy | 100+ 专家、并行协作、远程 IM 控制、企业技能包 | 一句话让 AI 处理业务流程 | 企业效率、AI 员工、场景套件、价格清晰 | 强调 Kimi 的通用复杂工作和内容/研究优势 |
| Kimi Work / Agent | Agent Swarm、Docs/Slides/Sheets/Websites/Deep Research、scheduled tasks、desktop/workflow | 从资料和目标到可用交付物 | 应转向真实任务、模板、达人案例、行业包 | 建 Kimi Work OS：场景 -> 教程 -> 模板 -> 达人 -> 数据 |

## 3. Claude / Anthropic

### 功能重点

Claude 的能力表达围绕：聊天、写作、研究、Artifacts、Projects、Skills、connectors、Claude Code、Claude Cowork、企业安全与管理。

### GTM 重点

Claude 的 GTM 不是只靠发布新模型，而是持续教育用户：

| 内容资产 | GTM 作用 |
|---|---|
| AI Fluency | 建立“会用 AI 是职业能力”的长期心智 |
| Claude 101 / Academy | 降低新用户启动门槛 |
| Claude for Work | 面向团队采购和职业场景 |
| Use cases / small business | 把抽象能力包装成业务流程 |
| Docs / agent guides | 服务开发者和高阶用户，建立可信深度 |

### Kimi 学习点

1. 官方账号要像“工作能力学校”，不是功能广播站。
2. 每个功能都要给用户一个“第一件可做的任务”。
3. 高付费用户需要被教育“我为什么值得为复杂任务完成付费”。

## 4. OpenAI Codex

### 功能重点

Codex 的核心是代理式执行：理解目标、读上下文、改文件、跑命令、验证、交付。面向非代码使用者时，Codex 的内容会把能力转成营销资产、报告、仪表盘、业务分析等“工作结果”。

### GTM 重点

Codex 的强点是“结果感”：它不是只给建议，而是能在工作区里做事。对非代码人群，最值得观察的是它如何把 coding agent 翻译成 business agent：

| 内容方向 | 对 Kimi 的启发 |
|---|---|
| Create campaign concepts and assets | Kimi 可以做营销活动全链路：洞察、概念、脚本、素材 brief、排期 |
| Finance reports / dashboards / decisions | Kimi 可以做数据分析、周报、决策 memo |
| Customer stories: Notion/Ramp | Kimi 需要真实团队案例和前后对比 |
| Prompt/task examples | Kimi 内容要提供可复制任务描述 |

### Kimi 应对

Kimi 不必和 Codex 比代码心智，而应强调：非代码知识工作者也能把 Kimi 当 agent 用，特别是中文资料、网页调研、文档交付、表格处理、PPT/网站生成。

## 5. Trae Work

### 功能和 GTM

Trae Work 的核心叙事是 AI-native workspace，强调 Work/Design/Code 多模式，以及从想法到产品的工作流。

### Kimi 应对

Trae 的优势在产品开发和工程语境。Kimi 要避开“开发者专属”的窄入口，主攻：

1. 市场、运营、内容、研究、学习、求职等更大的人群。
2. 中文长材料、复杂输入、多输出格式。
3. “一件真实工作交给 Kimi”而不是“构建一个项目”。

## 6. Qoder Work

### 功能重点

Qoder Work 明确把 agentic 能力带出代码场景，强调桌面、本地文件、浏览器自动化、Word/Excel/PPT/PDF 输出、Skills/MCP、IM channels、scheduled tasks。

### GTM 重点

Qoder Work 的案例表达很直接：一个任务原本要 1-2 天，现在几分钟到十几分钟完成。典型案例包括 Reddit 用户反馈研究、教育动画 demo、销售数据分析、博客配图寻找。

### Kimi 应对

Kimi 可以用同样的 before/after 结构，但更贴中文用户：

| Qoder 结构 | Kimi 版本 |
|---|---|
| Reddit feedback research | 小红书/知乎/微博用户反馈整理 |
| sales data analysis | 运营活动数据复盘和老板汇报 |
| blog image sourcing | 公众号/小红书选题和配图 brief |
| desktop local files | 本地资料夹到交付文档 |

## 7. WorkBuddy

### 功能重点

WorkBuddy 是场景化 AI 工作套件，强调 100+ 专家、并行协作、远程 IM 控制，以及电商、客服、设计、运营、数据、开发等业务技能。

### GTM 重点

WorkBuddy 把 AI 包装成“员工/专家/工作台”，并用价格、角色、业务流程降低采购判断成本。

### Kimi 应对

Kimi 要承认 WorkBuddy 在企业套件和 IM 控制上的强势，同时用以下角度差异化：

1. 更开放的复杂知识工作：研究、写作、学习、资料处理、创意策划。
2. 更强的中文内容生态：小红书、知乎、B 站、公众号、职场材料。
3. 更好的新用户教育：从 101 到任务模板，而不是直接丢给用户 100 个专家。

## 8. Kimi 的差异化主张

| 维度 | 竞品常见表达 | Kimi 应表达 |
|---|---|---|
| 产品定位 | AI assistant / coding agent / AI workspace | 中文复杂工作交付系统 |
| 用户入口 | 功能、专家、工作区 | 真实任务和真实材料 |
| 价值证明 | 模型能力、自动化、节省时间 | 最终交付物可保存、可修改、可复用 |
| 增长动作 | 功能发布、案例、课程 | 101 教育、行业工作流、达人共创、模板包 |
| 高付费人群 | 企业/开发者/团队 | 高任务压力、高资料密度、高交付要求的人 |

## 9. 高付费人群分类

| 人群 | 付费意愿来源 | 关键内容 |
|---|---|---|
| 小团队经营者 | 一个人要做多岗位工作 | 小团队 AI 工作包、周报、销售、内容、调研 |
| 产品/运营/市场 | 高频交付方案、报告、复盘 | GTM、竞品分析、活动复盘、增长实验 |
| 咨询/投研/商业分析 | 资料密度高、时间贵 | 深度研究、桌面文件、表格、报告 |
| 内容创作者/知识博主 | 内容产能直接影响收入 | 选题、脚本、资料库、爆款复盘 |
| 求职/留学/研究生 | 关键节点愿意付费 | 简历、申请、论文、文献、面试 |
| 管理者/项目经理 | 协调和复盘成本高 | 会议、项目计划、风险、行动清单 |

## 10. 竞品反推 Kimi 核心栏目

1. `Kimi Work 101`：新用户第一周任务。
2. `Agent Fluency`：教用户委派复杂任务。
3. `某某行业怎么用 Kimi`：岗位和行业场景。
4. `从文件夹到交付物`：展示多资料输入到文档/表格/PPT/网页。
5. `Kimi Agent Swarm 实战`：把多 agent 包装成多人协作成果。
6. `一天交给 Kimi`：用时间线展示连续任务处理。
7. `竞品同题挑战`：用同一个任务对比 Kimi 的中文场景优势。
