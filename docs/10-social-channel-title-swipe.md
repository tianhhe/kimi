# 社媒栏目与标题库

更新日期：2026-07-02

## 1. 方法说明

本文件把 Claude / Anthropic、Codex、Trae Work、Qoder Work、WorkBuddy 的官网、公开页面、搜索可见标题、产品案例和本地下载内容转成 Kimi 可执行的社媒栏目和标题库。

OpenCLI 已在旧工作区找到并升级到 `1.8.5`。Chrome 扩展桥接最初未连接，后改用 Edge 独立 profile 加载 OpenCLI extension `v1.0.21` 后连接成功，profile 为 `84x73kd6`。已用 OpenCLI 的 YouTube adapter 采样 Codex、Claude/Anthropic、Trae、Qoder、WorkBuddy 的公开视频标题。正文策略仍以“读完 Claude 内容后建设 Kimi 体系”为主，OpenCLI 标题只作为社媒表达参考。

## 10. 每条内容的检查清单

| 检查项 | 合格标准 |
|---|---|
| 人群 | 标题或开头能看出谁需要 |
| 任务 | 不是功能名，而是真实工作 |
| 输入 | 展示材料、网页、表格、截图或约束 |
| 过程 | 至少展示 Kimi 拆解或执行的关键步骤 |
| 输出 | 有完整结果截图或结果结构 |
| CTA | 评论领取模板、点击链接、打开 Kimi 试做 |
| 资产化 | 能沉淀到模板库或案例库 |

## 11. OpenCLI 后续补采计划

桥接恢复后，按下面顺序补全逐条作品标题：

1. 用 OpenCLI 进入 YouTube/X/LinkedIn/微博/小红书账号页。
2. 抓取作品标题、发布时间、播放/互动、链接。
3. 标注栏目：教育、发布、案例、客户、活动、技术、观点。
4. 记录到 `templates/competitor-tracker.csv`。
5. 每周把高价值标题转成 Kimi 选题，不直接照抄。
