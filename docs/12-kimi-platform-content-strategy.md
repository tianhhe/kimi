# Kimi 分平台内容策略

更新日期：2026-07-02

## 1. 总策略

Kimi 的社媒内容要像 Claude 的用户教育体系一样有层次，但表达要更适合中文平台：更强场景、更强结果、更短路径、更容易收藏和转发。

主线：`Kimi Work 101 -> Agent Fluency -> 岗位/行业工作流 -> Kimi Agent 进阶 -> 用户案例 -> 模板资产`

每个平台都承担一个不同任务，不把同一条内容机械搬运。

## 4. 小红书打法

小红书不适合讲抽象“AI agent”，适合讲“我遇到这个任务，Kimi 给我这个结果”。

| 栏目 | 发布频率 | 笔记结构 | 示例标题 |
|---|---:|---|---|
| Kimi Work 101 | 每周 3 条 | 痛点首图 -> 输入材料 -> 操作步骤 -> 结果截图 -> 模板口令 | 第一次用 Kimi Work，先试这 7 个真实任务 |
| 某某岗位怎么用 Kimi | 每周 3 条 | 人群痛点 -> 工作流图 -> Prompt -> 结果样例 | 产品经理怎么用 Kimi 做竞品分析 |
| Kimi 模板库 | 每周 4 条 | 模板名 -> 适用场景 -> 复制方式 -> 结果预览 | 周报不会写，直接复制这个 Kimi 模板 |
| 从文件夹到交付物 | 每周 2 条 | 一堆材料截图 -> Kimi 拆解 -> 输出结果 | 我把 20 页资料交给 Kimi，变成 5 分钟汇报 |

小红书视觉要求：

1. 首图必须出现“任务 + 结果”，不要只放品牌图。
2. 每篇至少 1 张结果截图，1 张步骤图，1 张模板图。
3. 评论区置顶关键词，例如“评论 竞品，领 Kimi 竞品分析模板”。

## 5. 抖音 / 视频号打法

短视频要把复杂任务压成 30-90 秒的结果演示。

| 栏目 | 视频结构 | 示例标题 |
|---|---|---|
| 一分钟交给 Kimi | 0-3 秒痛点，3-15 秒输入，15-45 秒过程，45-60 秒结果 | 老板 1 小时后要竞品分析，我把这件事交给 Kimi |
| 不用 Kimi vs 用 Kimi | 左右对比或时间对比 | 不用 Kimi 写周报 vs 用 Kimi 写周报 |
| Kimi Agent 实战 | 先说任务，再展示 agent 分工 | 一个 agent 查资料，一个 agent 做表格，一个 agent 写报告 |
| 今天让 Kimi 干一件事 | 连续日更任务 | 今天让 Kimi 帮我准备一次客户拜访 |

短视频脚本必须有 3 个画面：

1. 用户的原始输入：文件、网页、表格、截图、需求。
2. Kimi 的中间过程：拆解、追问、搜索、生成。
3. 最终交付物：文档、表格、PPT 大纲、行动清单。

## 6. B 站打法

B 站承担“让高意愿用户相信 Kimi 能做复杂工作”的任务。

| 系列 | 单集长度 | 首批选题 |
|---|---:|---|
| Kimi Work 从 0 到 1 | 12-20 分钟 | 新用户第一周 7 个任务、从资料夹到报告、如何迭代结果 |
| Kimi Agent 实战课 | 10-18 分钟 | Agent Swarm 做市场调研、做论文综述、做活动复盘 |
| 岗位工作流 | 8-15 分钟 | 产品、运营、市场、销售、研究生、求职者 |
| 竞品同题挑战 | 12-25 分钟 | Kimi vs 手动搜索、Kimi vs 普通聊天、Kimi vs 单点工具 |

B 站视频要提供资料包：原始任务、Prompt、结果样例、复盘说明。

## 7. 知乎 / 公众号打法

知乎和公众号承担搜索、解释、信任和沉淀。

| 内容类型 | 适合题目 | 结构 |
|---|---|---|
| 问答 | AI 工具到底怎么帮我写报告？Kimi Work 适合谁？ | 先回答结论，再给步骤和案例 |
| 横评 | Kimi Work、Claude Cowork、WorkBuddy、Qoder Work 区别是什么？ | 功能 -> 场景 -> 适合人群 -> 选择建议 |
| 手册 | Kimi Work 101、Agent Fluency、某岗位工作流 | 概念 -> 工作流 -> 模板 -> 案例 |
| 信任内容 | AI 处理文件安全吗？结果怎么校验？ | 边界 -> 方法 -> 用户责任 -> 最佳实践 |

公众号每月至少做 4 个资产包：

1. Kimi Work 101 新手包。
2. Agent Fluency 任务委派包。
3. 岗位工作流包。
4. 本月最佳用户案例包。

## 8. 即刻 / 微博打法

这两个平台适合让 Kimi 有产品人格和实时感。

| 栏目 | 内容 |
|---|---|
| Kimi 今日任务 | 每天发一个可以 10 分钟完成的 Kimi 任务 |
| 这个需求可以交给 Kimi | 把评论区用户需求改成任务描述 |
| Kimi 更新怎么用 | 新功能不发公告，发 3 个马上能用的场景 |
| 用户案例一句话 | 摘出用户工作流中的高光结果 |
| 竞品同题 | 看到竞品热内容后，做 Kimi 中文场景版 |

## 9. 社群打法

社群不是聊天群，是任务完成营。

| 周期 | 运营动作 |
|---|---|
| 每日 | 发一个 Kimi 任务卡，鼓励用户贴结果 |
| 每周 | 选 3 个用户案例，改造成官方内容 |
| 每两周 | 一场直播答疑：帮用户把真实任务改成 Kimi 工作流 |
| 每月 | 发布一个模板包和优秀案例榜 |

社群核心指标：7 日内完成高价值任务的用户数，而不是群人数。

## 11. 栏目验收

一个栏目连续 2 周低于基线就重做；连续 2 周高于基线就资产化。

| 指标 | 小红书 | 抖音/视频号 | B 站 | 知乎/公众号 |
|---|---:|---:|---:|---:|
| 有效内容标准 | 收藏率高于账号均值 30% | 完播高于均值 20% | 播放时长高于均值 20% | 赞藏/阅读完成高于均值 20% |
| 强转化标准 | 评论关键词/主页点击高 | 搜索/链接点击高 | 模板下载高 | 模板领取高 |
| 资产化动作 | 做模板合集 | 做系列剪辑 | 做课程合集 | 做长文手册 |
