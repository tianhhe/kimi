# 增长漏斗、功能使用率与复盘指标

更新日期：2026-07-02

## 1. 北极星指标

社媒带来的 7 日内高价值任务完成用户数。

高价值任务完成不是“打开 Kimi”或“问一句问题”，而是完成一个可感知结果：文档、表格、PPT 大纲、研究报告、简历、面试准备、竞品分析、活动复盘、选题表、会议行动清单等。

## 2. 增长漏斗

| 漏斗层 | 指标 | 定义 | 负责人 |
|---|---|---|---|
| 曝光 | impressions / views | 内容被看到的次数 | 渠道负责人 |
| 有效观看/阅读 | completion / read depth | 完播、阅读完成、停留时长 | 内容负责人 |
| 价值互动 | saves / comments / shares | 收藏、评论关键词、转发、私信 | 内容负责人 |
| 转化意图 | link clicks / search lift / keyword replies | 链接点击、搜索 Kimi、评论领模板 | 渠道负责人 |
| 到站 | landing visits | 落地页/模板页/下载页访问 | 数据 |
| 注册/登录 | signups / logins | 来自社媒归因的新用户或回流用户 | 数据 |
| 首次任务 | first task started | 用户开始第一个 Kimi 任务 | 产品/数据 |
| 高价值任务 | high-value task completed | 7 日内完成一个复杂结果 | 产品/数据 |
| 功能激活 | feature activated | 使用指定功能完成关键动作 | PMM/产品 |
| 留存/付费意向 | D7 return / upgrade click / paid conversion | 7 日回访、升级点击、付费 | 增长负责人 |

| 转化率 | 公式 | 用途 |

| 付费意向率 | 升级点击或付费 / 高价值任务完成 | 判断商业化质量 |

## 5. 功能使用率定义

功能 GTM 的核心问题不是“用户知道新功能了吗”，而是“用户是否在对应场景里用了它完成结果”。

| 功能 | 激活事件 | 高价值完成事件 | 内容包装 |
|---|---|---|---|
| Kimi Work | 创建/进入 Work 任务 | 输出可保存文档/表格/PPT/网页/报告 | 从文件夹到交付物 |
| Kimi Agent | 启动 agent 任务 | agent 完成计划中的关键步骤并产出结果 | 目标 -> 计划 -> 执行 -> 校验 -> 交付 |
| Agent Swarm | 使用多 agent/并行任务 | 多 agent 分工结果被合并成最终交付物 | 一个 agent 查资料，一个 agent 做表格，一个 agent 写报告 |
| Deep Research | 发起深度研究 | 生成含来源/结构/结论的研究报告 | 老板突然要市场调研 |
| Docs | 生成/编辑文档 | 文档被保存、复制、导出或继续编辑 | 方案、周报、复盘 |
| Slides | 生成 PPT/大纲 | 大纲或 slides 被保存/导出 | 资料夹到汇报 |
| Sheets | 生成/分析表格 | 表格被保存、下载或用于二次分析 | 竞品矩阵、活动复盘 |
| Websites | 生成网页/页面 | 页面被预览、保存或分享 | 活动页、作品集、报告页 |
| Scheduled Tasks | 创建定时任务 | 定时任务触发并被查看/复用 | 每周自动整理报告 |

## 6. 功能渗透看板

| 指标 | 公式 | 决策 |
|---|---|---|
| 功能曝光内容数 | 本周发布该功能相关内容数 | 判断 GTM 供给是否足够 |
| 功能内容有效率 | 功能内容有效互动 / 功能内容曝光 | 判断场景包装是否成立 |
| 功能入口点击率 | 功能入口点击 / 功能内容到站 | 判断 CTA 和落地页 |
| 功能激活率 | 功能激活用户 / 功能到站用户 | 判断产品上手 |
| 功能完成率 | 功能完成用户 / 功能激活用户 | 判断功能是否能完成任务 |
| 功能留存率 | 7 日内再次使用功能 / 功能激活用户 | 判断是否形成习惯 |

## 7. 内容到功能的映射

每条内容必须在 brief 中填写功能映射。

| 内容类型 | 主要功能 | 次要功能 | 成功事件 |
|---|---|---|---|
| 竞品分析 | Deep Research、Sheets、Docs | Agent | 输出竞品矩阵和结论 |
| 活动复盘 | Sheets、Docs | Agent | 输出复盘 memo 和行动清单 |
| 文献综述 | Deep Research、Docs | Agent | 输出文献矩阵和综述框架 |

| PPT 汇报 | Slides、Docs | Deep Research | 输出 PPT 大纲 |

## 8. 周复盘问题

每周五复盘必须回答：

1. 哪个平台贡献了最多高价值任务完成？
2. 哪个栏目带来的首用最高？
3. 哪个栏目收藏高但任务完成低？
4. 哪个功能内容曝光高但激活低？
5. 哪个功能激活高但完成低？
6. 哪类评论说明用户还没理解 Kimi？
7. 哪个达人带来了真实任务完成而不是只有曝光？
8. 下周要加码、停止、调整、资产化什么？

## 9. 决策规则

| 情况 | 判断 | 动作 |
|---|---|---|
| 曝光高、收藏高、任务完成高 | 内容和承接都成立 | 加码，做系列和达人复投 |
| 曝光高、收藏高、任务完成低 | 用户觉得有用但没去试 | 强化 CTA、模板入口、落地页 |
| 曝光高、功能激活低 | 功能包装不够具体 | 改成真实任务和结果演示 |
| 功能激活高、完成低 | 产品或教程卡住 | 补步骤教程、FAQ、引导 |
| 达人曝光高、转化低 | 粉丝不匹配或 CTA 弱 | 不复投或重写 brief |
| 社群任务完成高 | 场景有效 | 做官方案例和平台内容 |

## 10. 月度复盘输出

每月最后一个工作日输出：

1. 平台 ROI 表。
2. 栏目有效率排序。
3. 高付费人群贡献排序。
4. 功能使用率变化。
5. 达人复投名单和淘汰名单。
6. 下月主推功能和主推场景。
7. 下月预算和内容排期。
