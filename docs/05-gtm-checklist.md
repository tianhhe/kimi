# GTM Checklist

更新日期：2026-07-02

适用场景：功能发布、节点活动、模板包上线、达人集中投放、行业专题上线。

## 1. 发布前 14 天

| 检查项 | 标准 | 负责人 | 状态 |
|---|---|---|---|
| 发布目标 | 明确本次要拉动的核心指标 | PMM | 未开始 |
| 目标人群 | 至少定义 2 个核心人群和 1 个次级人群 | 增长 | 未开始 |
| 主场景 | 每个人群至少 1 个高价值任务场景 | 内容 | 未开始 |
| 核心信息 | 一句话定位、3 个卖点、3 个反例口径 | PMM | 未开始 |
| 转化路径 | 链接、口令、模板页、活动页可追踪 | 数据/增长 | 未开始 |
| 内容资产 | 官方账号首发内容、教程、FAQ、模板 | 内容 | 未开始 |
| 达人名单 | A/B/C 级达人池和档期确认 | 达人运营 | 未开始 |
| 风险口径 | 能力边界、数据安全、准确性说明 | 品牌/法务 | 未开始 |

## 4. 发布后 3 天

| 检查项 | 决策 |
|---|---|
| 哪个渠道贡献最高 | 加码内容和预算 |
| 哪个标题/封面最好 | 快速复刻 |
| 哪个问题被问最多 | 做 FAQ 或单独内容 |
| 哪个达人转化最好 | 复投或追加系列 |
| 哪个环节掉得最厉害 | 修落地页/CTA/教程 |

## 5. 发布后 7 天

必须完成一次复盘，沉淀到 `templates/weekly-review-template.md` 或单独复盘文档。

复盘问题：

1. 本次是否拉动了高价值任务完成用户数？
2. 哪个人群响应最好？
3. 哪个任务场景最能带转化？
4. 哪些内容值得进入常规栏目？
5. 哪些达人值得复投？
6. 哪些口径引发误解，需要修正？
7. 哪些资产可以沉淀为模板包？
